# Student Performance Prediction

Mini project using Linear Regression and PCA to predict student academic performance.

## Technologies Used
- Python
- Scikit-learn
- Pandas, NumPy
- Matplotlib, Seaborn

## Project Overview
This project predicts student final grades based on factors like study hours, 
attendance, previous grades, and stress levels using Linear Regression. 
PCA is applied for dimensionality reduction and model comparison.

## Results
- Baseline Model (without PCA): R² = 0.693
- PCA Model: R² = 0.514

## How to Run
```bash
pip3 install scikit-learn pandas numpy matplotlib seaborn
python3 student_performance_prediction.py
```
